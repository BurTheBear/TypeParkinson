# AI assistance — disclosure draft for team review

The [2026 Congressional App Challenge rules](https://www.congressionalappchallenge.us/wp-content/uploads/2026/05/2026-CAC-Rules.pdf) permit supporting AI use, require full disclosure, and require significant student contributions and understanding. This document records assistance known from the handoff and this session. It is **not a complete attestation of the students’ prior work** and must be reviewed and completed by Atharv Sharma and Pranav Atreya before submission.

## Known assistance

- **Claude Code**, according to the project handoff, assisted with earlier app development and the overhaul merged before this branch. The handoff describes a personal touch model, Bayesian correction, touch-pattern classification, activities, speech, history/reports and other app features. The exact division between student-authored and Claude-assisted code has not been established here; review that earlier history and disclose its scope rather than implying the assistance was limited to polish.
- **OpenAI Codex** continued the existing repository. It authored presentation code, 3D geometry/camera rendering, capture/encoding tools, website implementation, research notes and draft scripts. It also reviewed and changed native code for exports, microphone failure/countdown handling, keyboard Undo/selection/hold deletion, Reduce Motion, reminder saving/errors, tapping timing, and Speak preference refresh. It wrote additional regression cases. Those native changes/tests have not been built or run during this task.
- Codex used existing simulator captures, Chrome/DevTools, Node.js, Python and ffmpeg for the film/site, and official web sources for rule/cinematography research. It did not create a new app, submit a CAC application, merge upstream, buy credits or perform clinical testing.

## Team information to complete truthfully

Before using this as submission text, add each student’s actual design, implementation, debugging, testing and learning contributions; any additional AI tools, people, tutorials, libraries or reused assets; and how you reviewed and understood assisted work. Use concrete files or decisions where possible. Do not assign a role or invent an unaided coding story for either student.

Suggested opening, to adapt after reviewing the full history:

> We used Claude Code and OpenAI Codex for AI-assisted development, debugging, code review, presentation, website and writing support. We disclose the assisted areas in this document. Our individual contributions and the way we reviewed and understood this work are described in our application.

That last sentence is only appropriate once those contributions and review are actually documented in the application. Eligibility and the adequacy of student contribution are decided by the organizers, not by this disclosure draft.
